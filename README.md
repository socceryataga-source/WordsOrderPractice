# WORD ORDER — GitHub Pages 教材サイト

速読英単語の並び替え演習を、スマートフォン・Chromebook・PCで行う静的サイトです。

## GitHub Pages に公開する

1. ZIPを解凍し、`word-order-site` フォルダ内の **すべてのファイル・フォルダ**をGitHubリポジトリのルートにアップロードします。
2. リポジトリの **Settings → Pages → Build and deployment** で `Deploy from a branch` を選択し、`main` / `/(root)` に設定します。
3. 公開されたURLを開いて使用します。GitHub Pagesの反映には時間がかかることがあります。

サイトは `catalog.json` と `data/` のJSONを `fetch` で読み込むため、`index.html` をファイルとして直接開くと動作しません。必ずGitHub Pages等のHTTP(S)環境で開いてください。

## 現在の問題

- Level ★★ / 501–600：100題（元PDFの問題番号1〜100をサイト番号501〜600として登録）
- Level ★★★ / Level ★：データ追加に備えた空のレベル

## 後から問題を追加する方法

例：Level ★★ / 601–700 を追加

1. `data/level-2/601-700.json` を新規作成します。既存の `501-600.json` が書式の見本です。
2. `catalog.json` のレベル2の `ranges` に次の要素を追加します。

```json
{"id":"601-700","label":"601–700","file":"data/level-2/601-700.json"}
```

3. 新規JSONの `questions` に100問を記録します。各設問には以下が必要です。

```json
{
  "id": 601,
  "sourceNumber": 1,
  "japanese": "日本語の問題文",
  "prefix": "並び替え前の固定英文",
  "suffix": "並び替え後の固定英文",
  "tiles": ["並び替え対象語1", "並び替え対象語2"],
  "correctOrder": [1, 0],
  "answer": "完全な模範解答英文",
  "focus": "正答後に出すコロケーション・語法・文法の説明",
  "category": "Collocation & Usage"
}
```

- `tiles` は **PDFの括弧内の選択肢を記載順に** 文字列配列にしたもの。`also find` など、1選択肢にスペースが含まれる場合は1要素です。
- `correctOrder` は `tiles` の **0から始まるインデックス**を正しい語順に並べた配列です。同じ単語が2個ある場合もIDで厳密に採点します。
- `prefix` / `suffix` の句読点は原則として元のまま記載します。
- `id` は全範囲で重複しない通し番号にしてください。
- `category` には `Grammar` または `Collocation & Usage` を推奨します。

`level-3` のように新たなレベルを有効化する場合は、対応するJSONを置き、`catalog.json` の当該レベルの `ranges` に追加してください。レベルの空欄は押せません。

## 機能

- 20 / 50 / 100題（選択した範囲内で出題順は毎回ランダム）
- 5 / 8 / 10 / 15分・時間無制限
- タップ・ドラッグで単語移動、回答欄内の順序入れ替え、キーボード矢印キーでの並べ替え
- 全語を配置するとAnswerで採点、原文どおりの完全英文と日本語解説を表示
- 制限時間終了で即終了、正答率・進行率・未回答を別々に表示
- 間違い・未回答をCSVダウンロード（日本語文字化けに配慮したUTF-8 BOM）
- ミス問題だけの再挑戦（同一ブラウザセッション内）
- 最後の結果をブラウザのlocalStorageに保存（サーバーへの送信はなし）

## 教材原文の要確認事項

**`SOURCE_NOTES.md` を必ず確認してください。** 原PDF内の日本語・英文の不一致や不自然な表現があり、内容を勝手に変更せず原文どおり収録しています。

## サイト動作の確認

ローカルではこのディレクトリで `python -m http.server 8000` を実行し `http://localhost:8000/` にアクセスします。

Google Fontsを利用しています。ネットワークが切断された場合はデバイス既定のフォントに自動フォールバックします。GitHub Pages単体で利用可能で、外部API・登録は不要です。
